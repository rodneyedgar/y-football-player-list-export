Y-Football Player List Export

Export Yahoo Fantasy Player List data locally as CSV, TSV, or JSON without sending league data to a server.

Before You Start

  1. Log into Yahoo manually in your browser.
  2. Open the Yahoo Fantasy Player List you want to export.
  3. Set your desired filters.
  4. Use the controls below to export the visible page or walk through pagination.
